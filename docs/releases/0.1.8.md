## 新增：我的计划

- 左侧导航新增「我的计划」。
- 每条计划有名称，例如「第一周看网课」「第二周写真题」。
- 每条计划可以包含多个子任务，子任务支持完成勾选。
- 计划卡片显示完成进度，例如 `1/3 完成`。
- 计划和子任务都支持添加、编辑、删除。
- 计划不绑定日期、时间、任务类型或优先级。

## 时间轴

- 日期详情时间轴按「上午 / 下午 / 晚上」分段。
- 左侧显示任务名称、时间和与文字同尺寸的彩色方块。
- 右侧色条显示白色居中的预计花费时间，例如 `30分钟`、`1小时`、`2小时10分`。
- 首页不展示时间轴，点击具体日期后展示。
