方案 A · 推荐

自适应时间窗泳道

根据当天实际任务范围自动缩放到 07:00–23:00，放大时间条；左侧保留任务顺序和准确时间，右侧用颜色区分任务。

已完成 暂停 时间轴自动避开空白时段
优点任务条明显变宽，早上和晚上的安排都容易扫读。
取舍不是完整 00–24 点，需要标注当前可见时间范围。
适合大部分日程集中在 07:00–23:00 的日常使用。
方案 B

24 小时全景 + 时间卡片

保留完整 00:00–24:00，任务以带标题的白底彩边卡片展示，卡片下方保留精确时长细线。

已完成 暂停 完整查看一天
优点完整展示凌晨到深夜，任务名称直接可读，视觉更像日程卡片。
取舍凌晨空白多，普通时段任务条仍偏窄；卡片可能延伸超过真实结束时间。
适合需要同时查看凌晨、跨时段任务或完整一天的情况。
方案 C

上午 / 下午 / 晚上分段日程

把一天拆成三个时段，每个时段都有自己的时间轴；任务顺序和颜色不变，但一屏只需要读一小段。

已完成 暂停 按生活节奏分段
优点不用在一条很长的轴上找任务，上午 / 下午 / 晚上一眼分段。
取舍时间轴被拆开，跨段任务需要跨区对照，整体高度更大。
适合任务主要集中在固定三段、希望快速浏览的人。
